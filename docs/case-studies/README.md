# Case Studies

Case studies reconstruct complete contract packages from architectural decisions to
runtime outcomes. They complement the domain-neutral guides by linking every concept
to real repository artifacts and by naming the limits of the teaching implementation.

## Clinic Appointments

[Clinic Appointments: An End-to-End Case Study](clinic-appointments/README.md) follows
one booking promise through:

- Participant and authority boundaries
- The six-section agent contract
- FizzBee state, guards, and invariants
- Offers, uses, and condition quenching
- Contract loading and Google ADK construction
- Tool adapters and deterministic Python services
- Enforcement-twin tests and the complete offline gate
- Successful booking and slot-taken refusal paths
- Runtime assessment, current limitations, and one evolution scenario

Use its [artifact index](clinic-appointments/artifact-index.md) while browsing the
runnable example.
